# 新人上手

从根入口及项目现有测试标准或新人指南定位项目，现有章节直接更新或引用，不按模板另建新人文档或目录。

上手路线说明项目目标、关键业务链路、本人职责、权限与环境、有效测试数据及工具入口。各项链接到对应主文档，不要求新人先阅读全库；缺失的账号、数据和权限标明申请角色或待准备，不编造可用资源。

选择具备条件且适合新人的代表场景，提供：

准备什么 → 如何操作 → 到哪里观察 → 应看到什么 → 如何留证据。

关联该场景的已有用例和预期来源，必要时读取 [检索与用例复用](test-design.md)。由新人实际尝试设计或执行，将暴露的规则、环境和操作缺口分别更新到对应主文档，避免写成一次性聊天总结。

反馈上手路线、首个任务和未具备条件。完成指南不等于已独立上手；独立设计、评审和执行分别依据实际结果记录。以非原作者是否能完成任务、遗漏及返工评价资料效果。
